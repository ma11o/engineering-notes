## どこまでを根拠にできるか

仕様のMUST/SHOULDは、その仕様の対象範囲での要求である。製品のガイドは他の製品の保証ではなく、設計例は採用必須の規約ではない。StableなログモデルとDevelopmentの意味規約を同じ確定度で扱わない。

主張ごとの状態、該当節、技術的な留保は各根拠資料に記載している。書籍のページ番号と書誌情報は元のノートを保持したもので、本の本文を再閲覧したり書誌情報を再検証したりした結果ではない。実装言語・SDK・保存先の具体的な挙動、損失率、費用、法令・組織ごとの要件は検証していない。
