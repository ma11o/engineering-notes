# Engineering Notes

技術を自分の言葉で説明し、設計やレビューで判断するための学習ノート。テーマごとに、考え方の章と、根拠にした資料を分けて置いている。

## テーマ

- [ログ設計](logging/README.md) — 将来調べたい出来事を、後から比較し、つなぎ、説明できる形で残す
- [アーキテクチャの計測](architecture-metrics/README.md) — 設計の良し悪しを、目標に結びついた指標で確かめ、チームの判断に使う

## 読み方

- 各テーマの入口（README）から順に読む。根拠を確かめたいときは、各テーマの書籍ノートやリサーチ資料へ進む
- 書籍の要旨と、自分の解釈・補足は分けて書いている。例やしきい値は説明用で、そのまま採用する規約ではない
